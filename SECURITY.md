# Security Policy

SealedCash takes security reports seriously. Do not disclose vulnerabilities
in a public issue. Email [support@sealedcash.com](mailto:support@sealedcash.com)
with the subject `Security report: relayer` and include reproduction steps,
impact, and a safe contact method.

Do not include private keys, service tokens, or user transaction secrets in a
report. We will acknowledge a report within seven days and coordinate a fix
and disclosure timeline with the reporter.

This service is not production-ready merely because it starts. Operators are
responsible for independent contract, key-management, RPC, monitoring, and
deployment review.
