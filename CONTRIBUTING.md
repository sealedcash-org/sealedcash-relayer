# Contributing

Thanks for helping improve SealedCash. The official project is maintained by
[sealedcash-org](https://github.com/sealedcash-org).

1. Create a focused branch from the default branch.
2. Keep changes small and explain security or protocol assumptions.
3. Never commit credentials, private keys, production endpoints, or user data.
4. Run `npm run typecheck`, `npm run build`, and `npm test` before opening a
   pull request.
5. Update `CHANGELOG.md` for user-visible behavior.

By contributing, you agree that your contribution is provided under the MIT
License.
